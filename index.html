Editar no PhotoCraft

Plugin gratuito para o Figma. Selecione uma imagem, edite no PhotoCraft sem sair do Figma e, ao salvar com ⌘S, a imagem é trocada na hora. A original fica guardada na mesma camada.

Ver no GitHub Criado por @raphaelareas. O editor é o PhotoCraft, de código aberto, do time ArtCraft. Este plugin é independente.
