Privacy

Last updated: November 25, 2026

Edit in PhotoCraft is a free, independent plugin for Figma made by Raphael Arêas. In short: your images never leave your computer, and this site collects nothing about you.

Your images

When you edit an image, it goes from Figma to the editor and back inside the plugin window, on your own computer. No server receives, stores or sees your images.

This website and the editor

  • No cookies, no analytics, no ads, no tracking, no forms. That is why there is no cookie banner.
  • The site, the editor and the fonts are served by GitHub Pages. Like any web host, GitHub may log technical data such as your IP address. See the GitHub Privacy Statement.
  • The numbers on the home page (stars, downloads, version) are loaded by your browser from the public GitHub API, under the same GitHub policy.
  • Your language choice is saved only in your browser (local storage), so the page remembers it. You can clear it anytime in your browser settings.
  • The LinkedIn, Instagram and GitHub buttons are plain links. Those sites have their own policies once you open them.

The plugin

Inside Figma, the plugin saves only its own preferences (language, whether you saw the welcome screen) using Figma's local plugin storage on your computer, plus a small marker on the layers you edit so the next save updates the same image. Nothing is sent to the author.
