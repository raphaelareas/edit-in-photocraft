Editar no PhotoCraft

Salvou no PhotoCraft, atualiza no Figma. A original fica guardada.

1
Selecione uma camada com imagem
2
Rode o plugin e edite no PhotoCraft
3
Salve com ⌘ S e a imagem atualiza aqui

Para editar de novo, selecione a imagem e use ⌘ ⌥ P.
Enquanto edita, deixe este plugin rodando e não abra outros.
